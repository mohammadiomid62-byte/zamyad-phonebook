# دفترچه تلفن داخلی شرکت زامیاد

سامانه وبی دفترچه تلفن داخلی شرکت زامیاد، با رابط فارسی و راست‌به‌چپ.

## امکانات نسخه اولیه
- جستجوی سریع نام، نام خانوادگی، شماره پرسنلی، واحد و داخلی
- فیلتر واحد سازمانی
- نمایش وضعیت و اطلاعات تماس
- پنجره جزئیات شخص
- پنل مدیریت اولیه
- نگهداری داده در LocalStorage برای نسخه دمو
- معماری آماده برای اتصال آینده به API / SQL Server
- آماده‌سازی برای ورود اطلاعات از Excel

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## ساختار
- `index.html` رابط اصلی
- `css/phonebook.css` استایل
- `js/phonebook.js` منطق برنامه
- `data/phonebook-data.js` داده نمونه

> داده‌های نمونه آزمایشی هستند و نباید به‌عنوان اطلاعات واقعی کارکنان استفاده شوند.
